# Changelog

All notable changes to Focusfield are recorded here.

## [1.1.0] - 2026-11-20

### Added

- Light and dark modes, with Coral, Ocean, Forest, and Lavender color themes.
- Appearance page with palette previews and a sidebar mode switch.
- Saved appearance preferences applied across the timer, tasks, insights, and settings.
- Keyboard focus indicators on buttons.

### Fixed

- Appearance changes preserve running timer deadlines, task drafts, and unsaved preferences.
- Non-duration preference changes no longer extend a nearly finished timer.

## [1.0.0] - 2026-11-20

### Added

- Focus, short break, and long break timers with pause, resume, reset, and skip.
- Customizable session lengths and automatic break cycles.
- Task list with active task selection and completion tracking.
- Daily goals, seven-day activity chart, and session history.
- Desktop notifications, optional bell sound, and keyboard shortcuts.
- Local JSON persistence, offline operation, and a Linux application launcher.
- Portable Linux ZIP and Debian package builds.
