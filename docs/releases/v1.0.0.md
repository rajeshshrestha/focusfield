# Focusfield 1.0.0

The first public version of Focusfield, a calm, offline Pomodoro timer for Linux.

## Highlights

- Customizable focus sessions, short breaks, and long breaks.
- Task tracking, daily focus goals, session history, and insights.
- Desktop notifications and optional sound.
- Keyboard shortcuts, always-on-top option, and local data storage.
- Clean dark interface with no login or cloud dependency.

## Downloads

- **`focusfield_1.0.0_all.deb`** — Ubuntu, Debian, Linux Mint, and compatible systems.
- **`Focusfield_Linux_Portable.zip`** — portable Python/Tkinter version for Linux distributions.
- **`SHA256SUMS`** — SHA-256 checksums for both downloads.

### Install the Debian package

```bash
sudo apt install ./focusfield_1.0.0_all.deb
```

### Run the portable version

Install Python 3.9+ and your distribution's Tkinter package, extract the ZIP, then:

```bash
cd Focusfield
./run.sh
```

Run `./install.sh` to add a per-user launcher.

Personal data is kept in `~/.local/share/focusfield/state.json` (or under `XDG_DATA_HOME`).
