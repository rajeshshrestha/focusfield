Focusfield now adapts to your workspace with **light and dark modes** and four themes: **Coral, Ocean, Forest, and Lavender**.

Open **Appearance** in the sidebar to choose a palette, or use **Switch to light / Switch to dark** from any page. Your choice saves automatically without interrupting your timer or losing drafts. Existing tasks, session history, and preferences are preserved.

### Install or update

- Debian / Ubuntu / Mint: download `focusfield_1.1.0_all.deb` and run `sudo apt install ./focusfield_1.1.0_all.deb`.
- Other Linux distributions: extract `Focusfield_Linux_Portable.zip` and run `./run.sh`; optionally run `./install.sh` to update the per-user launcher. Requires Python 3.9+ and Tkinter.
- Verify downloads with `sha256sum --check SHA256SUMS` in the directory containing both assets.

This release also adds keyboard focus indicators and keeps nearly completed timers accurate when changing non-duration preferences.
